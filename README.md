## Overview

Personal Budget Manager gives individuals a single place to record transactions, organize spending by category, monitor budget limits, and review financial trends. It is designed to be fast to use, easy to understand, and useful from the first transaction.

---

## Why This Project

Most people know roughly what they earn but not where it goes. Spreadsheets are tedious to maintain, and many finance apps are complicated or locked behind subscriptions. This project aims to remove that friction with a focused tool that does a few things well:

- Make logging a transaction take seconds
- Show clearly whether you are on track this month
- Surface patterns you would otherwise miss

## Key Features

| Feature | Description |
|---|---|
| Transaction Management | Add, edit, and delete income and expense entries with amount, category, date, and notes. |
| Category Budgets | Set monthly limits per category and track how much of each is used. |
| Dashboard | See balance, total income, total expenses, and savings rate in one view. |
| Spending Insights | Review charts and summaries that highlight top categories and month-over-month changes. |
| Budget Alerts | Get a visible warning as a category approaches or exceeds its limit. |
| Search and Filter | Find transactions
